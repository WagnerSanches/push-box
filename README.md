# PushBox

## Como rodar
1. Abra o projeto pelo Unity Hub com o Unity 6 (6000.6.x).
2. Na aba Project, abra `Assets/Scenes/SampleScene` (na primeira vez o Unity pode abrir uma cena vazia "Untitled").
3. Aperte Play. Controles: mouse olha, WASD anda, Espaço chuta a caixa, R reinicia a fase.
